# Hartmann Arkitekter

En ny, statisk webbplats för Hartmann Arkitekter. Allt besökarinnehåll är på norska.

## Leverans

Den här mappen är den kompletta webbplatsen: index.html, undersidor, styles.css, script.js, lokala bilder, typsnitt, sitemap.xml och robots.txt. Ingen installation eller byggprocess krävs för att publicera dessa filer.

## GitHub Pages

1. Lägg **innehållet** i den här mappen i roten på ditt GitHub-repository. `index.html` ska ligga direkt i roten.
2. Behåll mapparna `assets/` och `prosjekter/` med alla filer.
3. Välj Settings → Pages → Deploy from a branch → main → / (root).
4. Vänta på att publiceringen blir klar. Öppna den adress som GitHub Pages visar.

Alla lokala länkar är relativa och fungerar även när GitHub Pages publicerar under ett repositorynamn. SEO-adresserna i canonical, sitemap.xml, robots.txt och strukturerad data ska bytas till den slutliga domänen när den bestäms.

## Innehåll och funktion

- 50 projekt med separata sidor, projektfakta och bildgallerier.
- Filtrering, sökning, tangentbordsstyrd bildvisning och mobilmeny.
- Sex medarbetare med publicerade kontaktuppgifter.
- Fagområder, låvombyggnad, perspektiv, arbetsmetod och kontakt.
- Interaktiv ritningssektion med originalplaner, snitt och fotografier från Torstad.
- Tjøme-studie som sammanför byggt resultat med originalsnitt, samt planarbete för Høn.
- Sex originalritningar för Torstad och Tjøme med förstoringslänkar och projektfakta.
- Tre länkar till fungerande originalartiklar. Artikeln ”Moderne boligdesign” utelämnades eftersom originaladressen gav 404 vid kontroll.
- Ingen serveransluten formulärtjänst. Kontakt sker direkt via e-post och telefon.
- Inga egna analysverktyg eller marknadsföringskapslar.

Uppgifter och bilder hämtades från https://www.hartark.no/ den 29–30 september 2026. Projektfaser återges som publicerade, inte som en ny kontroll av dagens byggstatus. Fotografier, illustrationer och ritningar märks separat. Bildkrediter i originalen har bevarats; Røa-projektet anger Taktil arkitekter för förprojektet. Bilder används i detta kundförslag och tillhör sina respektive rättighetsinnehavare.

Företagsinformation, projektuppgifter och personuppgifter bör godkännas av Hartmann innan kundens slutliga publicering. Förhandsversionen ersätter inte deras befintliga webbplats.
